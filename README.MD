# SalesDicoding - Landing Page Project

**SalesDicoding** adalah sebuah proyek website statis sederhana yang dikembangkan sebagai bagian dari tugas kursus **Belajar Dasar Pemrograman Web** di Dicoding. 

Proyek ini berfokus pada implementasi struktur HTML semantik dan styling menggunakan CSS murni untuk menciptakan tampilan halaman yang bersih.

## 🚀 Fitur Utama
- **Semantic HTML**: Struktur kode yang rapi menggunakan elemen HTML5.
- **Pure CSS**: Styling tanpa framework eksternal (Bootstrap/Tailwind).
- **Responsive Layout**: Optimal untuk tampilan desktop dan mobile.

## 🛠️ Teknologi
- **HTML5**
- **CSS3**

## 💻 Cara Menjalankan
1. Clone repositori ini.
2. Buka file `index.html` langsung di browser favoritmu.
